# Roadmap

Next steps, in no particular order. Open an issue if you want to take one.

- A `compare` command that puts two authors side by side in one report
- A hosted verifier page that reads a report JSON and explains each figure (issue #13)
- A `git workproof` subcommand entry, so the tool runs as `git workproof` (issue #49)

Done: a GitHub Action input that attaches a workproof summary to a release (`release: "true"`, issue #12, in 0.7.0).

Things deliberately not planned: anything that needs a server, a hosted account, or reads code content.
